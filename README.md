# jubilant-broccoli

Rust Fundamentals - Following Coursera Course

This repository contains examples and exercises from learning Rust fundamentals, covering:

- Variables and Mutability
- Data Types (integers, floats, booleans, characters, strings)
- Functions
- Control Flow (if/else, loops, while, for)

## Running the Project

```bash
# Build the project
cargo build

# Run the project
cargo run

# Run in release mode
cargo run --release
```

## Requirements

- Rust 1.70 or later
- Cargo (comes with Rust)
